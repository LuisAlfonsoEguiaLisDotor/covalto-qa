# Prueba Técnica QA - Covalto

Repositorio con los entregables de prueba técnica, por Luis Alfonso.

El proyecto está dividido en 3 carpetas:

- **1-diagnostico:** Reporte de los bugs visuales encontrados en la página web y el código HTML/CSS ya corregido.
- **2-api:** Script en Python para consumir y validar la API de Rick and Morty (tiempos de respuesta, status code y tipos de datos).
- **3-automatizacion:** Matriz de casos de prueba y script con Selenium para automatizar el flujo de registro en uTest.
